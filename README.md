# TO-BIM Academy

موقع إلكتروني واحترافي لمنصة **TO-BIM Academy** المتخصصة في تقديم أحدث الدورات والدبلومات الهندسية (في مجالات نمذجة معلومات المباني BIM، والتحليل الإنشائي، والتصميم المعماري، وأدوات البرمجة الهندسية باستخدام C++).

## 🚀 مميزات المشروع
* **ثيمات مخصصة لكل صفحة:** تصميم هندسي متكامل مع ألوان مميزة لكل مسار (البيم الإنشائي، البيم المعماري، الكورسات، والتواصل).
* **دعم اللغتين (AR/EN):** إمكانية تبديل لغة الموقع وعرض المحتوى بسلاسة.
* **قوائم منسدلة واحترافية:** لتسهيل التنقل بين الدبلومات الهندسية والصفحات الفرعية.
* **تصميم متجاوب (Responsive):** ملائم لجميع الأجهزة والشاشات.

## 🛠 التقنيات المستخدمة
* **HTML5**
* **CSS3 (Custom Variables & Grid)**
* **JavaScript (DOM Manipulation & Language Switcher)**
* **FontAwesome & Google Fonts (Cairo)**

## 📁 هيكل المشروع
- `index.html` : الصفحة الرئيسية (تعرض أبرز النشاطات والخدمات الهندسية والإحصائيات).
- `structural-bim.html` : صفحة دبلومة البيم الإنشائي.
- `architectural-bim.html` : صفحة دبلومة البيم المعماري.
- `courses.html` : صفحة الكورسات والبرامج الهندسية المنفصلة (Revit, 3ds Max, Navisworks).
- `contact.html` : صفحة التواصل ووسائل الاتصال الرسمية.
- `css/style.css` : ملف التنسيقات والأنماط الموحد.
- `js/script.js` : ملف التفاعل البرمجي وتبديل اللغات.
- `TOBIM.jpg` : الشعار الرسمي للمنصة.
